# Temas de Alya

Fondos de pantalla organizados **por tema**. El nombre del archivo siempre es
`tema_n.jpg`, donde `tema` es el nombre del tema y `n` el número consecutivo.
La app detecta los temas por ese patrón: **no se usa el nombre del personaje**.

## Estructura y formato
- Patrón: `tema_n.jpg/png` → `retro_1.jpg`, `retro_2.jpg`, … `retro_10.jpg`
- Numeración consecutiva desde 1, sin huecos.
- Vertical 9:16 (1080×1920 o similar), JPG optimizado (< 450 KB).

### Tema `retro` (10 fondos)
Ilustraciones de Alya (Alisa Mikhailovna Kujou, *Roshidere*) en clave retro / nostalgia:
luz cálida, escenas de colegio, atardeceres y ambiente noventero.

Las primeras 5 (`retro_1` … `retro_5`) son las originales; de `retro_6` a `retro_10`
se sumaron ilustraciones recopiladas de la web (Pinterest, DeviantArt, Civitai y
key visuals del anime). Todas aptas para todo público: sin desnudos ni poses sugerentes.
