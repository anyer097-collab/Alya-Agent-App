# Temas de Alya

Esta carpeta contiene los fondos de pantalla organizados por temas para Alya-Agent-App.

## Estructura
- `tema_n.jpg/png` (n = 1, 2, 3…)

Los archivos van dentro de `pictures-Alya/temas/`, con el nombre del tema en minúsculas y
un número consecutivo: `retro_1.jpg`, `retro_2.jpg`, … Formato vertical 9:16
(768×1376 o similar), JPG ligero (< 400 KB) para que cargue rápido en el teléfono.
