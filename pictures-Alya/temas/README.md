# Temas de Alya

Fondos de pantalla de Alya organizados por tema para Alya-Agent-App.

## Estructura y formato
- Nombre: `tema_n.jpg` → `retro_1.jpg`, `retro_2.jpg` … `alya_1.jpg` …
- Vertical 9:16 (1080×1920 o similar), JPG optimizado (< 450 KB) para carga rápida en el teléfono.

### Tema `alya`
Ilustraciones de Alya (Alisa Mikhailovna Kujou, *Roshidere*). Arte de terceros recopilado de la web
(Pinterest, DeviantArt, Civitai, key visuals del anime). Todas aptas para todo público:
sin desnudos ni poses sugerentes. Créditos de autoría al final.
